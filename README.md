# Kidney_Tumor
Kidney tumor project that comprehensively analyzes the kidney tumor by finding out its type, size, growth rate and the possible treatment and surviviability.

However, the kits19 datasets are several hundred GB and its checkpoints are huge as well. As a result, it is not added to GitHub.

You can access the datasets in the below link.

https://kits19.grand-challenge.org/data/
